## 3. Commands

### 3.1 `/tdd-red` — RED 단계 전용

| 항목 | 규칙 |
|------|------|
| 선언 | `Phase: RED \| Layer: ... \| Track: ...` |
| 절차 | ID 확인 → AAA → pytest **FAIL** |
| 변경 | **`tests/`만** |
| 금지 | `src/` 수정, Logic Domain Mock, assert 완화, GREEN/REFACTOR |

### 3.2 `/review-ecb` — ECB·계약 리뷰

| 항목 | 규칙 |
|------|------|
| 선언 | `Mode: Review ECB \| Scope: ...` |
| 출력 | 위반 항목 **표** + 총평 |
| 체크 5항 | C1 import · C2 E001~E005 · C3 int[6] 1-index · C4 SSOT · C5 Domain Mock |
| 금지 | **코드·테스트 수정** |
