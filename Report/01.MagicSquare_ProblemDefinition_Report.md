## 1. 개요

MagicSquare_1004는 4×4 부분 마방진(빈칸 2개, 1~16, 마법합 34)을 다루는 학습 과제이다.
STEP 1에서 Mom Test 인터뷰를 통해 **표면 문제**와 **진짜 문제**를 분리했고, 그 결과를 바탕으로 세션 3의 최소 범위(검증·판정)를 확정했다.

---

## 2. 도메인 정의

| 항목 | 규칙 |
|------|------|
| 격자 | 4×4 |
| 값 | `0`(빈칸) 또는 `1~16` |
| 빈칸 | **2개** (`0`) |
| 마법합 | **34** |
| 검증 대상 | **10선** — 행 4 + 열 4 + 대각선 2 |
| 완성 조건 | 1~16 중복 없음, 10선 각각 합 34 |

### 과제 (슬라이드 기준)

빈 칸 2개의 위치를 찾고 올바른 숫자를 채워 마방진을 완성한다.

---

## 3. 페르소나

**4×4 부분 마방진(빈칸 2개·0, 1~16, 합 34)을 손으로/코드로 다루는 학습자**

## 5. 문제 정의

### 5.1 표면 문제 (잘못된 정의 — 하지 않을 것)

**“4×4 부분 마방진을 ECB 구조의 Solver·Validator 프로그램으로 만들면, 빈 칸 2개를 빠르게 채우고 합 34를 맞출 수 있다.”**

- ‘만든다 / 프로그램 / Solver / ECB’가 문제 정의에 섞인 문장
- 이번 세션에서 **의도적으로 배제**하는 범위의 기준점

### 5.2 진짜 문제 (한 문장)

**4×4 부분 마방진에서 빈 칸 2개를 채운 뒤 10선(행·열·대각선) 합(34)이 맞는지 바로 판정하지 못해, 한 번의 시도만으로도 20분 가까이 시행착오를 반복한다.**

- 솔루션 이름 없음
- 불편·비용·판정·재현 중심
- Mom Test 증거 ②③에 기반

---

## 6. 세션 3 범위 (8계층 중 해당 항목)

### 주제 (한 문장)

**학습자가 빈칸 2개를 채운 4×4 격자에 대해, 10선 합이 34인지 손으로 더해 확인하지 않고도 즉시 판정할 수 있는 검증 규칙과 테스트 루프를 만든다.**

### R-G-I-O

| | 내용 |
|---|------|
| **Role** | 4×4 부분 마방진을 풀다가 “지금 합이 34가 맞나?”를 확인해야 하는 학습자 |
| **Goal** | 채워 넣은 격자가 마방진 조건(10선 합 34)을 만족하는지 맞음/틀림을 빠르게 알기 |
| **Input** | 4×4 정수 격자 — `0`(빈칸) 또는 `1~16`, 빈칸 2개 포함 |
| **Output** | 판정 결과 — `True` / `False` *(선택: 어느 선이 34가 아닌지)* |

### 성공 기준 (Mom Test 연결)

| # | 기준 | 증거 |
|---|------|------|
| 1 | 합 34가 **아닌** 격자 → 테스트 **Fail** | ③ “34가 안 맞아서” |
| 2 | 손 계산 20분이 아닌 **테스트 1회(수 초)** 로 동일 판정 | ② “20분 헤맸다” |
| 3 | 빈칸 2개(0) **부분 격자**도 검사 입력으로 처리 | ② “빈칸 2개 넣었다” |

### 이번 세션에서 하지 않을 것

| 제외 | 이유 |
|------|------|
| Solver (빈칸 자동 채우기) | 표면 문제 |
| MissingFinder (빈칸 위치 탐색) | 증거와 무관 |
| GridUI / InputHandler / ResultDisplay | 범위 밖 |
| ECB 전체 완성 | 세션 3는 Rule·Command·Test Loop만 |
| 힌트·자동 교정·KPI 약속 | Mom Test 위반 |

### 8계층 — 세션 3 산출물

| 계층 | 내용 |
|------|------|
| **Rule** | 4×4, 0=빈칸, 1~16, 마법합 34, 10선 검증, 1~16 중복 없음 |
| **Command** | `validate(grid)` — 10선 합 34 판정 |
| **(Skill)** | 줄 추출, `False` 시 어느 선이 틀렸는지 표시 *(선택)* |
| **Test Loop** | RED(틀린 격자) → GREEN(`validate` 구현) → REFACTOR |
