## `.cursorrules` 핵심 (초안)

| 영역 | 규칙 |
|------|------|
| 도메인 | 4×4, 빈칸 0×2, 1~16, 합 34, 출력 `int[6]` (1-index) |
| 오류 | `E001`~`E007` — boundary; entity는 `E001`~`E005` 처리 금지 |
| ECB | boundary→control→entity, entity→\* import 금지 |
| Dual-Track | Logic Mock 금지 / UI Mock 허용, `D-*`/`U-*`, `test_d_*`/`test_u_*` |
| TDD | RED→GREEN→REFACTOR, assert 완화·skip·xfail 금지, MagicConstant SSOT |
